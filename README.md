# Smash by Anas 🍔🔥

Smash by Anas is a modern responsive fast-food ordering website designed for online food delivery and customer engagement. The platform features premium burgers, loaded fries, mocktails, live order tracking, responsive layouts, customer/admin login portals, hover animations, and a trendy restaurant-style UI experience.

---

# 🚀 Features

* Fully responsive website for mobile, tablet, and desktop
* Premium modern UI/UX design
* Smooth scrolling navigation
* Interactive hover animations and transitions
* Fast food menu section
* Customer login portal
* Admin dashboard login
* Live order tracking section
* WhatsApp ordering section
* AI recommendation showcase section
* Modern glassmorphism cards
* SEO-friendly website structure
* GitHub Pages deployment support

---

# 💻 Technologies Used

* HTML5
* CSS3
* Tailwind CSS
* Responsive Web Design
* GitHub Pages Hosting
* JavaScript (UI interactions)
* Flexbox & CSS Grid
* Modern UI/UX Principles

---

# 🎯 Project Objective

The objective of this project is to build a professional online fast-food ordering platform with a responsive and visually attractive frontend suitable for restaurant startups, food delivery businesses, and modern digital food brands.
